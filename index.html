M

OpenAI 兼容、Anthropic、Google，以及 ChatGPT / Grok 账号登录与余额查询。

W

工作区

本地 Linux 沙盒，环境模板一键装好 Python / Node.js，长任务可转后台并在通知栏看进度。

K

安装步骤

  1. 1
    下载 APK

    在正式版或预览版中选择一个下载，当前仅支持 Android 设备。

  2. 2
    允许未知来源

    在「设置 → 安全 → 安装未知应用」中允许当前浏览器或文件管理器安装应用。

  3. 3
    安装并打开

    点击 APK 完成安装，首次启动后到「设置 → 服务商」填入你的 API Key 即可使用。
