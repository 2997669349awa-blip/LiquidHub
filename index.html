LiquidHub

液态玻璃风格的 Android LLM 聊天客户端。基于 RikkaHub 二次开发， 保留多服务商切换与全部原有能力，重做界面视觉。

L

液态玻璃界面

Haze 背景模糊叠加多层渐变与边缘高光，支持毛玻璃与光学折射两种效果，可在设置中切换。

M

多服务商切换

兼容 OpenAI、Anthropic、Google、DeepSeek 等任意 OpenAI 风格接口，模型自由切换。

A

深色 / AMOLED

纯黑背景搭配玻璃卡片，自动保证文字对比度，低于 Android 12 时降级为半透明纯色。

T

工具与 MCP

沿用上游的 MCP、搜索、工作区终端等能力，界面之外的功能保持一致。

W

Web 访问

内置 Ktor 服务，可在同一局域网通过浏览器访问对话。

O

AGPL-3.0 开源

作为 RikkaHub 的衍生作品，继续以 AGPL-3.0 发布，源码完全公开。

安装步骤

  1. 1
    下载 APK

    点击上方按钮下载安装包，当前仅支持 Android 设备。

  2. 2
    允许未知来源

    在「设置 → 安全 → 安装未知应用」中允许当前浏览器或文件管理器安装应用。

  3. 3
    安装并打开

    点击 APK 完成安装，首次启动后到「设置 → 服务商」填入你的 API Key 即可使用。
